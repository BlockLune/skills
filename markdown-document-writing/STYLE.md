# Markdown 风格参考

检查 Markdown 结构、排版和格式细节时使用本参考。

## 标题层级

- 文件需要标题时，使用一个 `#` 作为文档标题
- 使用 `##` 表示主要章节，使用 `###` 表示子章节
- 避免跳过层级，例如从 `#` 直接跳到 `###`
- 尽可能只使用一级到三级标题，不建议使用四级标题，禁止使用五级及以上标题

## 中英混排空格

中文与英文单词、数字、版本号、技术术语之间添加空格

正确：

- `使用 React 19 构建应用`
- `Next.js 16 支持新的功能`
- `在 VS Code 中打开项目`

错误：

- `使用React19构建应用`
- `Next.js16支持新的功能`
- `在VSCode中打开项目`

## 列表

同级项目使用无序列表，连续步骤使用有序列表。同一章节内保持列表标记风格一致。

## 表格

对比信息、字段说明或紧凑结构化数据适合使用表格。

如果普通段落或短列表更易读，不要强行使用表格。例如，如果表格只有 A、B 两列，那么使用 `- a: b` 而非表格

## 代码块

使用围栏代码块，并在已知语言时标注语言，例如 `bash`、`typescript`、`json`、`yaml`、`markdown`

## 图片

使用标准 Markdown 图片语法，尽量编写有说明性的 alt 文本

## 强调

- 如果基于已有文档进行修改，保留现有文档的粗体和斜体风格
- 新建文档时，尽可能不使用粗体、斜体
