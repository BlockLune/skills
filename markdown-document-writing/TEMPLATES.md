# Markdown 文档模板

这些结构只作为起点。应根据用户的实际文档目的调整，不要强行保留所有章节。

## README

1. 项目介绍
2. 功能特性
3. 安装方式
4. 使用方法
5. 配置说明
6. 开发或贡献指南
7. 许可证或致谢

## 技术文档

1. 概述
2. 背景或动机
3. 安装或准备工作
4. 使用方法
5. 配置或 API 参考
6. 示例
7. 常见问题或故障排查

## 教程

1. 目标
2. 前置条件
3. 分步操作
4. 验证结果
5. 总结
6. 后续步骤

## 报告

1. 背景
2. 方法或范围
3. 发现
4. 分析
5. 结论
6. 建议

## 设计方案

1. 上下文
2. 问题
3. 目标与非目标
4. 设计方案
5. 备选方案
6. 风险与权衡
7. 发布或实施计划
