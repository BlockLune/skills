# Markdown 文档撰写

用稳定流程产出干净的 Markdown：明确文档任务，规划结构，撰写聚焦内容，应用格式规范，并安全地完成格式化

## 流程

1. 明确文档任务
   - 确认文档类型、目标读者、用途，以及字数或模板限制
   - 只询问会阻塞推进的缺失需求
   - 完成标准：文档需要呈现的形态已经明确，或已经询问缺失需求

2. 先规划结构，再开始撰写
   - 根据文档类型选择合适的标题结构
   - 只有在标准结构有帮助时，才读取 [`TEMPLATES.md`](./TEMPLATES.md)
   - 如果有总字数要求，确定每个章节的字数
   - 完成标准：每个主要章节都有清楚的职责；有总字数要求时，每个章节已有字数预算

3. 撰写或修订内容
   - 保持段落聚焦
   - 只有在更易扫描或理解时，才使用列表、表格、图片和代码块
   - 如果有字数要求，使用 [`TOOLS.md`](./TOOLS.md) 中提供的工具进行字数检查
   - 完成标准：每个章节的内容都服务于该章节标题

4. 应用 Markdown 风格
   - 遵循 [`STYLE.md`](./STYLE.md)
   - 完成标准：标题、列表、表格、代码块、图片和中英混排空格保持一致

5. 安全格式化
   - 需要自动格式化或检查时，读取 [`TOOLS.md`](./TOOLS.md)
   - 未经用户同意，不安装工具，也不使用有破坏风险的重写命令
   - 完成标准：已经完成格式化，或说明了跳过格式化的原因

## 完成清单

- 文档有明确目的和目标读者
- 标题层级连续且有意义
- 列表、表格、代码块和图片格式一致
- 中英混排文本符合空格规则
- 有字数要求时，已进行字数检查
- 需要自动格式化时，已用安全方式处理
