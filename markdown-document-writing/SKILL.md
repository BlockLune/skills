# Markdown 文档撰写规范

本 skill 提供 Markdown 文档撰写的规范化流程，确保文档结构清晰、格式一致、内容高质量。

## 核心原则

### 1. 结构规划

在开始撰写前，先规划文档结构：

- 确定文档类型（技术文档、报告、README、教程等）
- 根据文档类型选择合适的章节结构
- 使用清晰的标题层级（`#`、`##`、`###`）
- 确保标题编号连续，不跳过层级

### 2. 字数控制

使用精确的中文字符统计方法（如需要统计纯中文内容）：

```bash
grep -oP '[\x{4e00}-\x{9fff}]' 文件名.md | wc -l
```

此命令只匹配汉字字符（CJK Unified Ideographs 范围），排除英文、数字、空格和标点符号。

### 3. 中英混排

中英文混合时必须添加空格。以下是正确和错误的示例：

- 正确：`Next.js 16`、`TypeScript`、`React 19`
- 错误：`Next.js16`、`TypeScriptReact`

这条规则适用于技术术语、版本号、函数名等所有中英混合场景。

### 4. 格式规范

- **粗体和斜体**：在开始撰写前，**询问用户**是否允许使用 `**粗体**` 或 `*斜体*` 进行强调。如果用户允许，在适当场景使用；如果用户不允许，则完全避免使用
- **适量使用表格**：在数据对比、表结构展示等场景使用表格
- **适量使用列表**：在功能点罗列、步骤说明等场景使用列表
- **使用小标题**：用二级标题（`##`）和三级标题（`###`）划分章节层次

### 5. 图片处理

在需要插入图片的位置使用标准语法：

```markdown
![图片描述](图片路径)
```

建议使用描述性的 alt 文本，便于可访问性。

## 撰写流程

### 第一步：了解文档需求

1. 确认文档类型和用途
2. 了解目标读者群体
3. 确认是否有指定的模板或结构要求
4. 确认字数要求（如有）

### 第二步：规划内容框架

根据文档类型设计章节结构。参考模式：

| 文档类型 | 典型结构 |
|----------|----------|
| 技术文档 | 概述 → 安装 → 使用 → 配置 → 常见问题 |
| 教程 | 简介 → 前提条件 → 步骤 → 总结 |
| 报告 | 背景 → 内容 → 结论/建议 |
| README | 项目介绍 → 特性 → 安装 → 使用 → 贡献 |

### 第三步：撰写初稿

按照规划的结构逐章节撰写：

- 段落长度适中，避免过长的"文字墙"
- 每个观点用简洁语言描述
- 技术细节适当展开，但不过度冗余
- 优先使用主动语态

### 第四步：格式规范检查

检查以下内容：

- 中英混排是否添加了空格
- 粗体和斜体使用是否恰当（根据用户偏好）
- 表格和列表的使用是否恰当
- 标题层级是否清晰连续
- 代码块是否正确标记语言

### 第五步：自动化格式处理

完成内容撰写后，执行以下自动化格式处理：

#### 5.1 Markdown 格式化

使用 `rumdl` 工具对 Markdown 文件进行标准化格式化：

首先检查工具是否已安装：

```bash
which rumdl
```

如果未安装，可选择以下任一方式安装：

```bash
# 方式1：使用 Rust/Cargo（推荐）
cargo install rumdl

# 方式2：使用 npm
npm install -g rumdl

# 方式3：使用 pip
pip install rumdl

# 方式4：直接下载二进制
curl -LsSf https://github.com/rvben/rumdl/releases/latest/download/rumdl-linux-x86_64.tar.gz | tar xzf - -C /usr/local/bin
```

安装或确认可用后，格式化目标文件：

```bash
# 格式化当前目录所有 Markdown 文件
rumdl fmt .

# 或格式化单个文件
rumdl fmt 文件名.md

# 如需先检查问题而不自动修复
rumdl check .

# 如需自动修复可修复的问题
rumdl check --fix .
```

#### 5.2 中英文混排自动修复

使用 `pangu` 工具自动修复中英文混排的空格问题：

```bash
npx pangu -f 文件名.md > 文件名.md
```

此工具会自动在中文和英文之间添加适当的空格。

## 常见问题处理

### 内容过长

当内容超出预期时，按以下优先级精简：

1. 删除重复的说明文字
2. 合并相似的功能点描述
3. 删除冗余的连接词和过渡句
4. 精简代码示例，保留核心逻辑

### 内容不足

当内容未达到预期时，按以下优先级扩充：

1. 增加背景说明和上下文
2. 补充技术细节和实现原理
3. 添加更多代码示例
4. 完善使用场景描述

### 格式不一致

确保全文格式统一：

- 标题层级统一使用 `#`、`##`、`###`
- 列表统一使用 `-` 或 `1.` 格式
- 表格统一使用 Markdown 表格语法
- 代码块指定语言标识符

### pangu 工具使用问题

如果 `npx pangu` 执行失败：

1. 确认 Node.js 环境已安装：`node --version`
2. 使用最新版本：`npx pangu@latest -f 文件名.md > 文件名.md`
3. 或全局安装后使用：`npm install -g pangu; pangu -f 文件名.md`

### rumdl 工具使用问题

如果 `rumdl` 执行失败：

1. 确认安装成功：`rumdl version`
2. 检查 PATH 中是否包含 rumdl 所在目录
3. 如果未安装，选择合适的安装方式（见上文）
4. 确保 cargo bin 目录在 PATH 中（Rust 安装方式）

## 详细格式规范

### 章节层级规范

| 层级 | 语法 | 使用场景 |
|------|------|----------|
| 一级标题 | `#` | 文档主标题 |
| 二级标题 | `##` | 主要章节 |
| 三级标题 | `###` | 子章节 |
| 四级标题 | `####` | 细分子章节（慎用） |

避免跳过标题层级（如 `#` 后直接使用 `####`）。

### 中英混排示例

| 正确写法 | 错误写法 |
|----------|----------|
| Next.js 16 | Next.js16 |
| React 19 | React19 |
| TypeScript | TypeScript |
| Node.js | Node.js |
| VS Code | VSCode |
| Vue 3 | Vue3 |

### 表格格式

```markdown
| 列1   | 列2   | 列3   |
|--------|--------|--------|
| 内容1 | 内容2 | 内容3 |
```

### 列表格式

无序列表：

```markdown
主要特性：
- 特性一
- 特性二
- 特性三
```

有序列表：

```markdown
操作步骤：
1. 第一步
2. 第二步
3. 第三步
```

### 代码块格式

```markdown
```语言
代码内容
```
```

常用语言标识：`bash`、`javascript`、`typescript`、`python`、`json`、`yaml`、`markdown`、`sql` 等。

## 自动化工具详解

### rumdl（Markdown 格式化）

`rumdl` 是高性能的 Markdown 检查和格式化工具（rvben/rumdl）。

**核心命令：**

```bash
# 检查问题（不修改文件）
rumdl check .

# 格式化文件（始终退出 0）
rumdl fmt .

# 自动修复（修复可修复的问题）
rumdl check --fix .

# 预览修复 diff
rumdl check --diff .
```

**进阶用法：**

```bash
# 禁用特定规则
rumdl check --disable MD013,MD033 .

# 排除特定目录
rumdl check --exclude "node_modules,dist" .

# 仅包含特定文件
rumdl check --include "docs/*.md" .

# 初始化配置文件
rumdl init

# 查看规则详情
rumdl rule MD013
```

**支持的文件格式（flavors）：**

| Flavor | 适用场景 |
|--------|----------|
| standard | 标准 Markdown |
| gfm | GitHub 风格 |
| mkdocs | MkDocs 文档 |
| mdx | MDX 文件 |
| quarto | Quarto 文档 |

### pangu（中文混排自动修复）

`pangu` 自动在中文和英文之间添加空格。

**安装和使用：**

```bash
# 使用 npx 直接运行（推荐）
npx pangu -f 文件名.md > 文件名.md

# 全局安装后使用
npm install -g pangu
pangu -f 文件名.md
```

**功能：**

- 自动检测中文和英文混合的文本
- 在中文字符和英文字母之间添加适当空格
- 处理技术术语、版本号、URL 等

### 推荐工作流程

```bash
# 1. 使用 rumdl 检查 Markdown 问题
rumdl check .

# 2. 使用 rumdl 格式化 Markdown
rumdl fmt .

# 3. 使用 pangu 修复中英文混排
npx pangu -f *.md > *.md

# 4. 再次使用 rumdl 确保格式一致
rumdl fmt .
```

## 检查清单

完成文档后，逐项检查：

- [ ] 文档结构清晰，标题层级连续
- [ ] 中英混排全部添加了空格
- [ ] 粗体和斜体使用符合用户偏好
- [ ] 表格格式正确
- [ ] 列表格式统一
- [ ] 代码块标注了语言
- [ ] 无多余空行或格式混乱
- [ ] 已运行 rumdl 格式化
- [ ] 已运行 pangu 修复混排（如有中文内容）
